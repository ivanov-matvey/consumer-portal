## Quick Start

### Backend

```bash
cd C:\consumer-portal\backend\ConsumerPortal.Api
dotnet run
```

Swagger: <https://localhost:7079/swagger>

### Frontend

```bash
cd C:\consumer-portal\frontend
npm run serve
```

Application: <http://localhost:8080>
